# Business Project Management

Streamlit project tracker using Supabase PostgreSQL.

## Streamlit Cloud
- Main file: `app.py`
- Python: 3.12
- Add `DATABASE_URL` in app Secrets.
- Keep database credentials out of GitHub.

This app uses tables prefixed with `bpm_` so it can share a Supabase project without altering Perfect Laundry CRM tables.
